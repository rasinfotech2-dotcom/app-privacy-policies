3. Android Permissions & Media Handling

To enable offline media management, playback, and editing, Status & Reels Saver Pro requests strictly sanctioned Android APIs:

  • Scoped Media Storage (MediaStore): On Android 10+, the Application saves user-processed images, videos, and audio clips directly to standard Android MediaStore directories (e.g. Movies/, Pictures/, Download/) without requiring legacy broad storage access permissions.
  • Storage Access Framework (SAF): When the user chooses custom backup or source directories, the Application uses Android's system directory picker (ACTION_OPEN_DOCUMENT_TREE) accessing solely the folder explicitly granted by the user.
  • Package Visibility (<queries>): The Application queries whether specific messenger or social client applications are installed on the device solely to present targeted sharing and launch options. The broad QUERY_ALL_PACKAGES permission is never requested.
  • Notification Permission (POST_NOTIFICATIONS): On Android 13+, optional notification permission enables offline daily streak tracking and utility alerts. All notifications are scheduled 100% locally on the device.

  • Store Review Safe Mode: All ad networks and telemetry are silenced during store review evaluations.
  • You can reset or opt out of personalized advertising anytime via your Android device settings: Settings → Google → Ads → Delete advertising ID.
